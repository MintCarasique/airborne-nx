# AirborneNX

Порт Xbox 360 версии **Medal of Honor: Airborne** на Nintendo Switch (homebrew) через статическую
перекомпиляцию PowerPC → C++ → AArch64.

> Репозиторий не содержит файлов игры. Нужен собственный дамп Xbox 360 (GOD-контейнер с `default.xex`).
> Каталоги с игрой, извлечёнными ассетами, сгенерированным кодом и сборками исключены в `.gitignore`.

## Состояние (2026-10-23)

- `default.xex` перекомпилирован XenonRecomp (317 единиц трансляции), собирается под AArch64 с libnx.
- Собственный рантайм `runtime/` реализует ~114 из 267 импортов ядра.
- Графика: Mesa NVK под Horizon; на Switch показываются кадры вступительного ролика (медленно).
- PC-сборка останавливается на `XMADisableContext`; меню не достигнуто.

Подробный разбор и план: [docs/ASSESSMENT.md](docs/ASSESSMENT.md). История работ: [analysis/README.md](analysis/README.md).

## Структура

| Путь | Содержимое |
|---|---|
| `runtime/` | рантайм: ядро Xbox (HLE), GPU, аудио, файлы, сеть, слой Switch |
| `tools/` | извлечение GOD/XEX, перекомпиляция, сборка, шейдеры, упаковка; `tools/tests` — тесты |
| `tools/patches/` | изменения к XenonRecomp/XenosRecomp |
| `config/` | конфигурация перекомпиляции и зависимостей |
| `analysis/` | заметки и результаты аппаратных прогонов (сырые логи хранятся локально) |
| `docs/` | документация проекта |
