AirborneNX 0.5 — Vulkan/NVK + запуск настоящего кода игры

Это промежуточная сборка порта. Изображения игры, звука и игрового процесса пока нет.
Она запускает код Airborne, создаёт Vulkan-устройство через NVK и обрабатывает
поддерживаемые команды Xenos. Неподдерживаемая отрисовка/показ кадра останавливает
запуск с объяснением, без имитации успешной отрисовки.

Установка и один запуск:
1. Распакуйте папку switch из архива в корень SD-карты.
2. Откройте hbmenu в режиме приложения (удерживая R при запуске установленной игры).
   Режим альбома не подходит из-за необходимого объёма памяти.
3. Запустите airborne-nx-entry-v0.5. Не переносите старые файлы версии 0.4 поверх неё.
4. Дождитесь остановки. На ПК остановка достигнута в VdSwap — это пока предел порта.
   На Switch возможна более ранняя остановка в NVK; журнал содержит операции и коды.
5. Нажмите + один раз. Сборка записывает результаты ожидания потоков, освобождения
   Vulkan и памяти. Если безопасный выход невозможен, она попросит закрыть через HOME.
6. После выхода пришлите один файл:
   /switch/airborne-nx-entry-v0.5/result-v0.5.txt

Если HOS снова покажет ошибку при выходе, сохраните её код вместе с этим журналом.
Все связанные этапы выполняются за один запуск. Старые проверки отображения памяти
и CPU отдельно запускать не требуется. Игровые ресурсы целиком для этого этапа не нужны.

Сборка скомпилирована для ARM64 и связана с NVK. Её работа на Switch до вашего
запуска не подтверждена. Контрольные суммы находятся в SHA256SUMS.txt.
