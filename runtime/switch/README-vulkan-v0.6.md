AirborneNX 0.6 — выполнение начальных операций графики игры

Эта версия выполняет начальную очистку глубины/трафарета через очередь Vulkan,
восстанавливает начальный буфер изображения и передаёт его в окно Switch через
NVK. Это ещё не игровой экран: первый буфер инициализации чёрный. Общая отрисовка,
видеосинхронизация, меню, звук и игровой процесс не реализованы.

На ПК код игры выполнил 1024 графических пакета, обработчик GPU-прерывания и
передачу начального буфера с обратным чтением пикселей. Текущая остановка на ПК —
WAIT_REG_MEM: ожидается ещё не реализованный сигнал. На Switch новый путь
передачи окна и выполнения GPU-команд до вашего запуска не подтверждён.

Один запуск:
1. Распакуйте папку switch в корень SD-карты.
2. Запускайте hbmenu в режиме приложения (R при запуске установленной игры).
3. Откройте airborne-nx-entry-v0.6. Старые сборки можно оставить отдельно.
4. Дождитесь остановки и возврата текстового экрана. Чёрный экран может появиться
   ненадолго при передаче окна Vulkan; это ожидаемый начальный буфер игры.
5. После очистки ресурсов нажмите + для выхода. Если будет указано HOME_REQUIRED,
   закройте приложение через HOME. Если HOS покажет ошибку, сохраните её код.
6. Пришлите один файл /switch/airborne-nx-entry-v0.6/result-v0.6.txt.

Журнал включает выделение ресурсов, команды, ожидание завершения GPU, параметры
окна/форматы, передачу пикселей, прерывание игры и завершение потоков/памяти.
Отдельные старые проверки CPU и отображения памяти повторять не нужно.
Полный набор игровых ресурсов для этого начального этапа не требуется.

Сборка не заменяет аппаратно проверенную 0.5. Контрольные суммы — SHA256SUMS.txt.
