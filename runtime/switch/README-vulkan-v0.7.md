AirborneNX 0.7 — вступительный ролик через Vulkan

Сборка запускает оригинальный код Xbox 360. Он читает и декодирует вступительный
WMV, а Vulkan выполняет настоящие шейдеры ролика, преобразует Y/U/V в цветной
кадр и передаёт игровой буфер в окно Switch. На ПК получены реальные кадры
заставки из предоставленной копии игры. Этот новый путь на Switch ещё не проверен.
Меню и игровой процесс пока не подтверждены. Декодирование звука XMA не реализовано.
Текущая остановка на ПК — XMADisableContext при инициализации звука; ролик может
прерваться до конца. Это известное ограничение, а не признак повреждения ресурсов.

Установка за один перенос:
1. Скопируйте готовую папку dist/switch/airborne-nx-entry-v0.7 целиком в /switch/
   на SD-карте. Внутри должны быть NRO, image.bin, xex-header.bin и папка game.
   game/MOHAGame содержит ресурсы вашей копии игры. Для них нужно около 6,4 ГБ.
2. Если используется небольшой ZIP, распакуйте его в корень SD, затем скопируйте
   extracted/base/MOHAGame в /switch/airborne-nx-entry-v0.7/game/MOHAGame.
   ZIP содержит только исполняемую сборку; игровых ресурсов в нём нет.
3. Запустите hbmenu в режиме приложения: удерживайте R при запуске установленной
   игры. Откройте airborne-nx-entry-v0.7. Старые сборки можно оставить отдельно.
4. Дождитесь изображения. Начальный чёрный кадр и пауза загрузки допустимы;
   скорость нового пути на Switch ещё неизвестна. Предел одного запуска — 120 с.
5. После остановки и очистки ресурсов нажмите + для выхода. Если указано
   HOME_REQUIRED, закройте приложение через HOME. При ошибке HOS сохраните её код.

Для оценки одного запуска нужны result-v0.7.txt и короткое описание: появилась
ли заставка, двигалась ли картинка, дошла ли до следующего экрана. Повторять
старые проверки CPU/памяти не требуется. Журнал содержит ID сборки, файловые
чтения, графические операции, результат передачи кадра и очистку ресурсов.
Частые вызовы блокировок записываются выборочно, с отдельными полными счётчиками,
чтобы не тормозить ролик постоянной записью на SD. Ошибки не скрываются.

Версия 0.6 и её аппаратные результаты сохранены отдельно. Контрольные суммы
файлов сборки — SHA256SUMS.txt; ресурсов — GAME_SHA256SUMS.txt в готовой папке.
