AirborneNX — тест CPU на Nintendo Switch, версия 0.1
==================================================

Это диагностическое homebrew-приложение, не запускаемая версия Medal of Honor.
Полного игрового runtime, графики и звука в этом NRO нет.

1. Скопируй папку switch из архива в корень SD-карты. Структура:
   /switch/airborne-nx-probe/airborne-nx-probe.nro
   /switch/airborne-nx-probe/image.bin
2. Запусти AirborneNX CPU Probe через уже установленный hbmenu.
3. Дождись строки RESULT=PASS либо RESULT=FAIL. Нажми + для выхода.
4. Пришли содержимое /switch/airborne-nx-probe/result.txt.
   Также укажи модель Switch, версию системного ПО/Atmosphere и способ запуска
   hbmenu (Applet Mode из альбома или режим приложения).
   Если приложение вылетело до создания файла — пришли код ошибки с экрана.

Что проверяется:
- точный SHA-256 локального нормализованного образа игры;
- 768 вызовов настоящей рекомпилированной функции 0x828B6D00;
- 1 138 867 исполнений сгенерированных инструкций FLOAT16_2 на ARM64;
- монотонность таймера с частотой 50 МГц.

Функция игры выполняется отдельно и читает образ через проверяемый callback.
Полная 4-гигабайтная гостевая память и точка входа игры здесь не запускаются.
Программа читает image.bin и записывает result.txt рядом с NRO.

Сборка и линковка проверены на ПК. Исполнение на физической Switch ещё
не проверено — именно для этого нужен этот тест. Бинарник создан для Switch
на libnx/devkitA64; Windows x64 runtime в него не включён.
